## 🌲 What is TouchGrass AI?

TouchGrass AI is built on a radical design principle: **the screen should be the shortest part of the experience**.

Instead of an addictive chatbot or SaaS dashboard, TouchGrass AI is a tactile, pocket-first field companion:
1. **Plan in 30 seconds** — tailor a walk to your schedule, fitness, and interests.
2. **Download an offline pack** — verified OpenStreetMap routes and sensory quests cached on-device.
3. **Put your phone in your pocket** — minimal *Outdoor Mode* with zero notification noise.
4. **Touch grass** — explore the living world, snap nature photos, and record voice notes.
5. **Return home** — receive an automatic digital scrapbook journal generated by local open models.

---

## ⚡ Key Highlights

- 🌿 **Nature-First Aesthetic**: High-contrast **Daylight** and **Dark Moss** outdoor themes.
- 🧭 **Pocket-First Outdoor Mode**: Displays only what matters—your current sensory mission and walk timer.
- 📍 **Deterministic Geometry**: Uses OpenStreetMap & OSRM. **Zero hallucinated trails or fake coordinates**.
- 📴 **100% Offline-First**: Complete packs saved in IndexedDB. Operates seamlessly in Airplane Mode.
- 🔒 **Zero-Telemetry Privacy**: Location traces, photos, and notes stay strictly on your device.
- 🤖 **Open-Weight Edge AI**: Powered by **Gemma 2 2B**, **Moondream**, and **Whisper** via Ollama (with instant zero-dependency fallback).

## 🏗️ Architecture

```
[ Web Browser / PWA ]  <--->  [ IndexedDB + Service Worker ] (100% Offline Packs)
         |
         v (REST API)
[ FastAPI Backend ]   ----->  [ OpenStreetMap / OSRM ]       (Real Physical Routes)
         |
         +----------------->  [ Ollama Local Engine ]        (Gemma 2 / Moondream / Whisper)
         |
         +----------------->  [ Local SQLite Database ]      (Zero Cloud Telemetry)
```

## 💻 Quickstart & Local Setup

### 1. Clone & Configure
```bash
git clone https://github.com/adityanathpatel/TouchGrassAI.git
cd TouchGrassAI
cp .env.example .env
```

### 2. Backend (FastAPI)
```bash
cd backend
python -m venv .venv

# Windows:
.venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate

pip install -r requirements.txt
pytest
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```
> API runs at: `http://127.0.0.1:8000` (Interactive docs at `/docs`)

### 3. Frontend (React + Vite)
In a second terminal window:
```bash
cd frontend
npm install
npm run dev
```
> Web application runs at: `http://localhost:5173/`

### 4. Local AI (Optional - Ollama)
```bash
ollama pull gemma2:2b
ollama pull moondream
ollama serve
```
*(If Ollama is not running, TouchGrass AI automatically engages its built-in zero-dependency deterministic fallback engine).*
